# Журнал хакатона

## Что было до VENTUREHACK

Прошлый проект команды Tamyr: исследование проблемы гибели городских саженцев, официальные цифры, дизайн экранов и питч.

## Что сделано за 48 часов отборочного этапа

Код этого репозитория написан заново (см. историю коммитов):

- движок причины гибели с проверкой поливов по датчику и объяснением вывода;
- симулятор района и оценка точности движка на 30 сценариях;
- карта, паспорт саженца с QR, графики, история событий;
- проверка фото горожанина (GPS, дата, повторы, индекс зелени);
- автонаряды на полив и акт для акимата с печатью в PDF;
- импорт CSV датчика, прошивка ESP32, скрипты реальной погоды и NDVI;
- опрос и интервью для валидации, сценарий демо.

Сторонние библиотеки и данные перечислены в README («Что разработано командой, а что взято готовым»). При разработке использовались инструменты ИИ.
